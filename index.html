    Kebijakan Privasi Duit Gue

    Terakhir diperbarui: Oktober 2026


    Duit Gue berkomitmen untuk melindungi privasi data penggunanya. Aplikasi ini dibuat untuk membantu mahasiswa mencatat keuangan secara mandiri.


    1. Penyimpanan Data

    Seluruh data transaksi, budget, dan profil Anda disimpan secara lokal di perangkat Anda (LocalStorage). Kami TIDAK memiliki server pusat dan TIDAK mengumpulkan data pribadi Anda ke internet.


    2. Keamanan

    Karena data disimpan di perangkat Anda, keamanan data bergantung pada keamanan perangkat Anda. Kami menyarankan Anda untuk rutin menggunakan fitur "Backup Data" agar data tidak hilang jika perangkat rusak atau cache terhapus.


    3. Perizinan

    Aplikasi ini tidak meminta akses ke kamera, mikrofon, atau lokasi Anda. Akses galeri hanya digunakan jika Anda secara sukarela mengganti foto profil.
